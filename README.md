# macOS 15 VNC через GitHub Actions

Поднимает macOS 15 (arm64) на раннере GitHub Actions с доступом по VNC. Без ngrok — только бесплатные туннели без регистрации.

## Способы подключения

| Способ | Что нужно | Где взять адрес |
|---|---|---|
| Браузер (noVNC) | Ничего | Лог шага `Connection info` → `https://xxx.trycloudflare.com/vnc.html` |
| VNC-клиент | RealVNC Viewer / TigerVNC | `bore.pub:PORT` из того же лога |

## Подключение

Вход: **vncuser** / секрет `VNC_USER_PASSWORD` (Sequoia принимает только учётку, не legacy-VNC пароль). При входе Safari открывается автоматически.

## Пароли

Подключение по **VNC-паролю** (без логина) — попадаешь сразу в живую сессию `runner` с открытым Safari:

- **Password:** секрет репозитория `VNC_PASSWORD` (8 символов)
- Username, если клиент его спрашивает, — оставь пустым

Запасная учётка macOS: `vncuser` / секрет `VNC_USER_PASSWORD`.

## Как запустить

1. Actions → **macOS 15 VNC** → **Run workflow** → Run
2. Дождаться шага `Connection info` (~3–5 минут)
3. Открыть ссылку из лога, ввести VNC password, залогиниться как `vncuser`

## Ограничения

- Один запуск живёт **до 6 часов** (лимит GitHub-hosted раннеров), потом просто перезапусти workflow
- Новая сессия = новый адрес туннеля и новый раннер, состояние не сохраняется
- Повторный запуск отменяет предыдущий (concurrency group)

## ⚠️

GitHub официально не разрешает использовать Actions как VPS. Для периодических тестов GUI обычно прокатывает, но при регулярном круглосуточном использовании аккаунт могут забанить.
